# sample data

`focus_sample_100000.csv.gz` is the 100,000 row sample from the
[FOCUS Sample Data](https://github.com/FinOps-Open-Cost-and-Usage-Spec/FOCUS-Sample-Data)
repo of the FinOps Foundation: anonymized real billing data from AWS, Microsoft Azure,
Oracle Cloud and Google Cloud in the FOCUS 1.0 format.
